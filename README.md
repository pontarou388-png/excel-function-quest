# エクセル関数クエスト

宇宙ペンギンといっしょにExcel関数を覚える4択クイズです。1セクション約3分。

## できること

- 4コース・全38問（超基本 / 条件つき / 検索・参照 / 文字・日付）
- 出題は3パターン（関数の役割・正しい式・実行結果の予想）
- 解答すると即座に正誤＋「書き方」「使用例」「ひとこと解説」を表示
- まちがえた問題は要復習リストに自動でたまり、正解すると消える
- バッジ6種と最高記録のコレクション
- オリジナルBGM（自作曲 kankanFX）付き。右下のボタンでいつでも再生／停止、音量調整も可能
- タイマー・効果音はオン／オフ切り替え可能
- キーボード操作：1〜4で選択、Enterで次へ

## 使い方

`index.html` をブラウザで開くだけです。GitHub Pages に置く場合は Settings → Pages で公開ブランチを指定してください。

## 技術メモ

- HTML / CSS / JavaScript のみ。ビルド不要、外部ライブラリなし
- 通信は Google Fonts（Zen Maru Gothic）の読み込みのみ。APIキーや個人情報は一切扱いません
- 学習記録は閲覧している端末の localStorage にのみ保存され、サーバーには送信されません
- 効果音は Web Audio API で生成。BGMのみ mp3 を同梱しています（約8MB）
- ブラウザの自動再生制限のため、BGMは画面を最初にクリック／タップした時点で流れはじめます

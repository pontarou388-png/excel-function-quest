アプリの入れ方

エクセル関数クエストを、パソコンやスマホにアプリとして入れる方法です。

このゲームは、ブラウザで開くだけでも遊べます。アプリとして入れると、ホーム画面やデスクトップのアイコンから すぐ開けて、ブラウザのバーが消えて画面が広く使えます。電波がないところでも遊べます（BGMは通信が必要です）。 お金はかかりません。ふつうのアプリのようにストアからダウンロードするのではなく、ページから直接追加します。

パソコン（Chrome・Edge）

  1. ChromeまたはEdgeで ゲームのページ を開く
  2. アドレスバー（URLが出ている場所）の右はしにある インストールのマーク（⊕ や、画面にモニターと↓が描かれたマーク）をクリック
  3. 出てきた小窓の 「インストール」 をクリック
  4. デスクトップとスタートメニューにアイコンができます。次からはそのアイコンをダブルクリックで開けます

マークが見つからないときは、右上の 「…」（Edgeは「…」→アプリ）→ 「キャスト、保存、共有」→「ページをアプリとしてインストール」 からでも入れられます。SafariやFirefoxでは、このインストール機能は使えません。

iPhone・iPad（Safari）

  1. Safari でゲームのページを開く（ChromeアプリではなくSafariです）
  2. 画面の下にある 共有ボタン（四角から上向きの矢印が出たマーク）をタップ
  3. メニューを下にスクロールして 「ホーム画面に追加」 をタップ
  4. 右上の 「追加」 をタップ。ホーム画面にペンギンのアイコンができます

「ホーム画面に追加」が見つからないときは、メニューのいちばん下の「アクションを編集」から追加できます。

Android（Chrome）

  1. Chrome でゲームのページを開く
  2. 画面の下または上に 「アプリをインストール」 の帯が出たら、それをタップ（出ないときは次へ）
  3. 右上の 「︙」 をタップ → 「アプリをインストール」 または 「ホーム画面に追加」 を選ぶ
  4. 「インストール」 をタップ。ホーム画面にアイコンができます

よくある質問

お金はかかりますか？

かかりません。広告もありません。

消したいときは？

スマホは、ホーム画面のアイコンを長押しして削除します。パソコンは、アプリを開いて右上の「…」→「アンインストール」を選びます。学習の記録も一緒に消えます。

記録はどこに保存されますか？

使っている端末の中だけです。ほかの人に見られることはありません。そのかわり、スマホとパソコンで記録は別々になります。

新しくなったのに画面が変わりません

アプリをいったん閉じて、開き直してください。それでも変わらないときは、ブラウザでページを開いて再読み込みしてください。

インストールのマークが出てきません

ブラウザが対応していない可能性があります。パソコンはChromeかEdge、iPhoneはSafari、AndroidはChromeでお試しください。入れなくても、ブラウザのページからそのまま遊べます。
